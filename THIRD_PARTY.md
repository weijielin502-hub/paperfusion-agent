# Third-party components

`paper2code/` is the Paper2Code/PaperCoder project by Minju Seo, Jinheon Baek, Seongyun Lee and Sung Ju Hwang, copied from the user's personal POC. The embedded repository reports commit `ba9169978043d5799c8d4f4a0963e6b66a24c2e1` and retains its [Apache-2.0 license](paper2code/LICENSE). PaperFusion uses its Planning, Analyzing and Coding scripts through a separate checked wrapper. The vendor code is not claimed as original PaperFusion work.

The RRF case cites G. V. Cormack, C. L. A. Clarke and Stefan Büttcher, “Reciprocal Rank Fusion outperforms Condorcet and individual Rank Learning Methods,” SIGIR 2009. Its `paper.json` is a short original summary and project contract, not a copy of the PDF. The PDF is linked rather than redistributed.

The upstream Transformer example PDF is present in the local copy for development but excluded from the publishable Git snapshot. The structured example JSON and upstream source code remain available for offline Paper2Code setup.
